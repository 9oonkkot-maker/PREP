# 프렙 카페

문서와 시안을 기준으로 판매·메뉴 수익성, 비용·손익, 재고 관리·백업·복원을 구현한 웹 프로그램입니다. 사용자 확인 전에는 EPIC 완료로 처리하지 않습니다. 진행 상태와 검사 근거는 `docs/04_개발계획.md`, `docs/05_테스트결과.md`에 기록합니다.

## 실행

Node.js 24.x에서 실행합니다.

```text
npm ci
npm test
npm run build
npm run preview
```

테스트 화면: http://127.0.0.1:5173/

같은 주소와 같은 브라우저에서 사용해야 저장된 자료가 이어집니다. 최초 가상 샘플을 한 번 반영하고 운영 기록은 브라우저의 IndexedDB에 저장합니다. 실제 기록을 외부 서버로 전송하지 않습니다. 사이트 데이터를 지우면 로컬 기록을 잃을 수 있습니다. 운영비용·데이터 화면에서 전체 JSON 백업을 내려받아 개인 보관 장소에 저장하세요. 다른 주소에서 이용할 때는 해당 백업으로 복원하세요.

프로그램을 수정하며 개발할 때는 `npm run dev`를 사용합니다. 현재 검사용 화면은 배포용 빌드의 미리보기 서버로 제공합니다. 이 서버가 실행 중인 동안 브라우저를 다시 열어 테스트할 수 있습니다.

## 구현 범위

- 제공 JSON 초기 반영과 구조·연결 검사
- 날짜·메뉴·채널별 판매 조회·등록·수정·단건/선택 삭제
- 당시 개당원가 보존, 날짜별 가격·채널별 원가와 재료 소모 계산
- 일·월·분류별 메뉴 수익성, 읽기 전용 레시피 근거
- 실제 저장, 다른 탭의 오래된 수정 차단, 원자적 쓰기와 오류 안내

- 비용 등록·수정·삭제, 일·월 손익과 실제 기록 그래프
- 재료 잔량·근거 조회, 입고·폐기·마감 실측 등록·수정·삭제
- 전체 JSON 백업·검증·교체 복원, 복원 실패 시 모든 표 복구

엑셀 가져오기·양식, 주·분기·반기·연간, 예상 손익·발주 추천은 2차 범위입니다. Vercel 배포는 아직 실행하지 않았습니다. Vercel에서 Vite 프로젝트로 연결하고 빌드 명령 `npm run build`, 출력 폴더 `dist`, Node.js 24.x를 사용합니다. 해시 주소로 화면을 전환하므로 별도 서버 경로 설정이 필요하지 않습니다.

저장소에는 직접 구성한 가상 샘플만 포함합니다. 사용자가 브라우저에 입력한 기록, 운영 백업, 환경변수, 설치 폴더와 빌드 결과는 커밋하지 않습니다. 운영 백업 파일은 `backups/`에 보관하거나 `prep_backup_*.json` 이름을 유지하세요.

자동 검사는 계산·실제 IndexedDB 인터페이스를 사용하는 테스트 환경을 포함합니다. 브라우저의 실제 화면 확인과 사용자 확인을 별도로 기록합니다.
